# AI Productivity Hub

Build a modern, responsive web app called AI Workplace Productivity Assistant that helps professionals manage workplace tasks using AI.

Include:

AI Task Planner: Generate personalised daily/weekly schedules and prioritise tasks based on the user’s input.

AI Research Assistant: Summarise topics/articles and generate relevant insights and recommendations.

AI Chatbot: Interactive workplace assistant that responds intelligently to user prompts.

Dashboard UI: Clean SaaS-style dashboard with sidebar navigation.

Editable AI outputs so users can modify generated results.

Responsible AI disclaimer explaining that AI responses should be reviewed.

Important: All task plans, research summaries, recommendations, and chatbot responses must be AI-generated dynamically from the user’s input. Do not use generic, hard-coded, placeholder, or pre-written responses.

Use a clean, professional light-blue design with responsive layouts for desktop and mobile.

Focus only on the frontend and AI interaction experience. Do not create backend development, database functionality, or sign-up/sign-in pages.
